A guard for agents that sign what they're handed. Paste what a key was asked to sign — a digest, a payload, or EIP-712 typed data — and see exactly what the signature would grant before it exists.

Runs entirely in your browser: no backend, no wallet connection, no RPC calls, no analytics. Nothing you paste leaves this page — the checker is the same library the CLI ships, bundled into one file. Never paste a private key or seed phrase — the guard only needs public payload bytes.
EIP-712 typed data (optional JSON — shown automatically for 0x19 0x01 payloads)

Examples — from the repo's own fixtures, nothing invented

The Binance 14 bytes are real chain data — carrier tx 0xad99264d…, block 26300753, decoded byte-by-byte by 808bits. This project does not claim it would have stopped that incident — the signer was compromised upstream. Same guard code as the CLI — they cannot disagree. MIT licensed.
